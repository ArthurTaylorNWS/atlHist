# History of Storm Surge Modeling and Guidance

| Year | Milestone |
| :--- | :--- |
| **1969** | Hurricane Camille |
| **1970's** | SPLASH Model (to shore) |
| **1980's** | SLOSH Model (overland) |
| **1985** | Hurricane Elena |
| **1986** | MEOW/MOM |
| **1989** | Evacuation Study |
| **1995** | ETSS 1.0 Model (to shore) |
| **1997** | Real-Time Deterministic Surge |
| **2003** | Hurricane Isabel => P-Surge 1.0 |
| **2005** | Hurricane Katrina |
| **2008** | P-Surge 1.0 (Storm Surge ensembles); Hurricane Ike => AGL Concept |
| **2009** | SLOSH + SWAN (3rd gen Wave) |
| **2011** | SLOSH + Tides |
| **2012** | Hurricane Sandy => ET focus |
| **2014** | P-Surge 2.0 (Surge + Tide ensemble) |
| **2015** | Tropical Inundation Graphic; ETSS 2.0 overland surge and tide |
| **2017** | Tropical Storm Surge Warning; Hurricanes Harvey, Irma, Maria; P-ETSS 1.0; SLOSH + GLWM |
| **2020** | P-ETSS 1.1; Hurricanes Laura, Marco (Simultaneous) |
| **2021** | P-Surge 2.9 (utilize NHC fcst of RMW) |
| **2022** | Transition to WCOSS 2 |
| **2023** | P-Surge 3.0; P-ETSS 1.2 (Fine Res Alaska) |
